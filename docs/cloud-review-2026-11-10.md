## 已修复

1. **学习草稿读取失败后覆盖旧记录（高优先级）**：原前端无论 GET 成功与否，都会在 300ms 后 PUT 浏览器缓存；原后端又整份替换。现仅在成功读取后同步变化的题目，服务端在同一数据库锁内合并，保留未见过的其他题目草稿。空更新不清空旧记录，验证失败或超限不改库。
2. **保存失败与异步覆盖（高优先级）**：原错误被静默吞掉，后发请求可能先完成。现逐次串行保存，按修改版本清除待同步标记，失败显示重试入口。未确认保存的草稿保留在当前浏览器，重开后不会被旧服务端内容覆盖。初次读取较慢时打开题目，也不会把尚未读到的笔记替换为空白。
3. **原卷纠正页无法恢复预览**：如果索引页先失败，后续题号定位给出正确页时，学习桌旧的失败状态一直存在。现换页自动重置失败状态，校正页与后续翻页可重新显示。
4. **测试依赖私人原卷**：Luna 预览链路的常规 Rust 测试原先硬编码本机私人 PDF。现生成 20 页合成 PDF，经真实 PdfCraft 引擎测试页图、授权范围门槛与独立复核流程，不把模拟提供方当真实模型接通。
5. **云端可复现性**：启动器遵循 `STUDY_PDFCRAFT_BIN`；Cargo 测试/构建使用锁文件；补充私有数据/凭据忽略项与 GitHub 自动回归工作流。

## 功能与产品审查

- **原卷直读**：原页图与题号定位、失败回退均已存在，本轮修复了纠正页的恢复路径。全库题面、图表、共享材料及 QP/MS 配对尚未逐题审核，不能把已迁移题数当识别准确率。
- **章节双语与题库分析**：已有自然考纲顺序、正式考纲中英文、排名和筛选入口。此次云端不带用户题库，真实全库的分布与零覆盖统计没有重算。
- **定义库**：现有物理 33 / 经济 28 仍是已核对样本，不是全库定义覆盖。原文、整理背诵版和去重统计区分合理；仍需要扩展真实原卷样本、核对缺失来源，而非用样本频率推算出题概率。
- **自动识别**：任务领取、提交、独立复核、异常队列和可选账户连接代码已存在；Luna 真实账户未授权、真实模型准确率未知。不得在此次结果中声称已接通或能全自动准确入库。
- **下一轮建议**：优先在本机隔离副本完成真实题库的学习桌/定义来源/组卷视觉验收，再继续扩定义来源与题面边界。多窗口同时编辑同一道题仍采用最后一次提交生效，尚无同题冲突合并界面；浏览器存储关闭且后端离线时需保持窗口打开并重试。

## 验证命令

```sh
npm --prefix web ci
python3 -m pip install -r requirements.txt
export STUDY_PDFCRAFT_BIN=/absolute/path/to/pdfcraft-cli
./scripts/test-all.sh
```
