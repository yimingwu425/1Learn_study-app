# 定义库：来源、答案版本与统计（2026-11-09）

当前支持本机已有的物理 9702 与经济 9708。首批物理 33 个定义、71 次已确认考查，经济 28 个定义、41 次已确认考查。来源跨 2020–2026；这不是对所有真题定义的穷尽识别。

## 使用

侧栏“定义库” → 选择学科、考纲章节、年份；可搜索中英文或考纲编号。主列表默认依考纲自然顺序，右侧展示当前范围的已确认排行和年份次数，也可按已确认次数排序。英文背诵版与中文理解同等可读，可遮住答案回忆。

“核对评分标准与原题”保留每次试卷、年份、小问题号、QP/MS 页码、真实原文截图、文件 ID 和 SHA-256。可切换同一定义的不同年份记录，再进入原题学习或打开完整原卷。

## 不混用的答案版本

- 英文背诵版和中文理解是依据评分要求整理的学习表达，不冒充 Cambridge 逐字官方原文。
- 书面题保留对应官方评分条目的原文及真实截图；只合并提取文字的空白，图上保留原样。
- 选择题保留官方答案字母。定义文字引用正确选项，并明确其来自 QP，而非把 MS 字母表说成完整定义答案。
- 定义得分点不能代替论述题的图示、分析及评价。不同题境对措辞与内容的要求应查该次评分标准。
- 实际 GDP 的一个 2025 MS 条目含疑似错误算式，保留原图并标注；整理版只采用其经过物价变动校正的文字定义，不沿用该算式。

## 考频口径

从 271 份原卷的可读文字检索找到 114 处候选；逐项区分实际定义请求、推导/单位应用及情境解释，匹配真实评分小问。当前 61 个术语共 112 个“术语—小问”记录。一个请求可要求两个不同定义，因此记录数可以多于原始触发短语数。

同一 QP 文件 SHA、同一小问题号、同一术语只计一次，旧题库的重复标签、多个知识点和多份复制记录不叠加。相同定义在不同正式卷号/变式出现，保留为不同真卷；同一题要求两个不同术语时各记录一次。年份、章节、关键词过滤后重新计算次数、不同原卷数和排行。

“不同原卷数”按 QP 文件哈希去重。接口校验当前本地 QP/MS 与已核对源哈希；缺失或改变的原件记录从当前可用统计排除并提示，避免沿用失效证据。目录版本及 catalogSha256 供核对运行实例加载的数据版本。

文字层损坏、扫描页、未使用这些问法的定义及未明确题干的内容仍可能漏检。没有用旧标签中的 define 或 definition 直接计数；“使用功率定义推导公式”等不重复计作定义题。“未收录”不等于“没考过”。次数不是完整题库概率，也不是未来出题预测。

## 数据和技术

运行接口为 Rust GET `/api/definitions`，参数 subject、chapter、year_from、year_to、query、sort、offset、limit；未知参数或无效范围明确拒绝。主业务 SQLite 不新增/覆盖题目或笔记。原卷渲染仍用已接入的成熟 PdfCraft，不调用 Python 或任何 AI。

目录在 `server/assets/definitions/catalog.json`，整理版本在 `terms.tsv`，人工分类与来源指纹在 `reviewed-mapping.json`。原件未写回。构建时采用独立 PyMuPDF 作为开发核对器：

```
.venv/bin/python tools/discover_definition_sources.py
.venv/bin/python tools/prepare_definition_catalog.py
```

新候选必须经过来源指纹和复核映射；不按数组位置自动套用旧审阅结果。无法匹配原有已审阅来源时构建失败，新候选未审阅时不计入考频。目录原子写入，生成完成后再构建并重启 Rust；不能并发读取正在生成的数据版本。

未实现自动运行 Luna 的全库定义发现、自动补全所有缺失题面、自动独立复核和所有其他学科。Luna 正式授权另见 `luna-subscription-assessment.md`，当前功能并不以它已接通为前提。

## 验证

`verification/definition-regression/report.json` 包含两科全量目录、独立次数计算、章节/年份及非法参数、8 个真实来源案例和旋转 MS 页面尺寸/源哈希检查。Rust 测试检查重复记录不增计、缺失来源不混入和自然筛选，界面测试检查双语、原文/整理答案分离、选择题来源及空范围提示。

实际 Mac Chrome 页面已经验证双语答案、旋转评分条目、YED 公式、选择题来源类型及章节年份筛选。真实浏览器截图以 `mac-browser-*.jpg` 保存在同一证据目录，原 PDF 独立核对图为 `*-source-row.png`；两者不互相冒充。

备份与最终原数据保护检查见 `verification/definition-backup.json` 和 `verification/definition-final.json`。C-Paper 工程和数据库未修改；这里只提供自身稳定的来源标识和校验依据。
